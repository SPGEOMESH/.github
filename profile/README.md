
SPGEOMESH is a modular spherical geometry mesh codebase for astronomy and heliophysics applications. 

### Top Level Project (SPRiemann)

Currently, the top level project of this group is [SPRiemann](https://github.com/SPGEOMESH/CSRiemann).
Visit this project via the link for a quick start.

> SPGEOMESH is a `dgcalc` group. Some other groups are:
> * [DGCALC](https://github.com/DGCALC/DGCALC)
> * [SPGEOMESH](https://github.com/SPGEOMESH/SPGEOMESH)
> * [SPECTRUM-MHD](https://github.com/SPECTRUM-MHD/SPECTRUM-MHD)
> 
> To read documentation about groups, visit the [DGCALC README](https://github.com/DGCALC/DGCALC).
